# Smart Traffic Prediction using Graph Neural Networks

Academic Pre-Final Year project for Advanced Database.

## Project Focus

The project treats advanced database technologies as the core of the system and integrates Graph Neural Networks for traffic prediction.

### Core technologies
- PostgreSQL - relational traffic data and analytics
- PostGIS - spatial data and spatial queries
- Neo4j - road-network graph and graph traversal
- FastAPI - backend API layer
- React.js + Plotly - web dashboard
- PyTorch Geometric - GNN traffic prediction

## Development Phases

1. System and database architecture
2. PostgreSQL + PostGIS
3. Neo4j graph database
4. Traffic analytics
5. GNN model
6. FastAPI
7. React dashboard
8. Integration
9. Testing and debugging
10. Documentation and viva preparation

## Academic Scope

The system demonstrates relational databases, normalization, constraints, complex SQL, joins, aggregation, indexing, query optimization, spatial databases, graph databases, Cypher, graph traversal, and integration of database systems with an ML pipeline.

> Development will be completed phase-by-phase. Sample/generated data, where used, will be clearly identified and will not be presented as real-world traffic results.
